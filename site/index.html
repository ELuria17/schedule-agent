A scheduler that plans your week, not just your inbox.

Reads tasks from Canvas or your todo app, places them around your classes and meetings with a deterministic solver, and pings you when something's slipping. Runs on your Mac. Data stays local.

01 · the premise

Paying $34/month for scheduling is wild when the math is a few hundred lines of Python.

Motion and Reclaim figured out something real: placing tasks around your fixed time is a constraint problem, and solving it for you is genuinely useful. Charging a subscription to do math on your own calendar is the part that doesn't survive scrutiny.

This is that solver, wrapped in a small hub you can open from any browser on your machine. Your tasks live in SQLite on your laptop. Your calendar sits on iCloud. Your API key is your business. The code is MIT-licensed and boring — no startup, no telemetry, no cloud component you can't see.

02 · what it does

Six things, each honest about its job.

01

Deterministic solver

Greedy placement with chunk splitting, deadline pressure, priority tiers, and an overdue-tolerant fallback. Math, not vibes. Never schedules during class.

02

Pluggable providers

Canvas LMS, iCloud CalDAV, Apple Reminders, iMessage, ntfy.sh shipped. Each is one Python class against a small ABC. Adding Google Calendar or Todoist is a file, not a rewrite.

03

Review gate, optional

Turn on require_approval per source and new tasks land in a pending queue before they hit your calendar. Good for noisy LMS or when you're letting the agent draft tasks from incoming messages.

04

Anthropic agent, also optional

Tell it "ENGL essay due Friday, ~90 minutes" and it files the task. The LLM handles intake and daily summaries; the deterministic solver handles placement. You can run the hub without the agent if you want.

05

SQLite, all of it

Task history, solver log, agent session transcripts — all persist. Restart the process, redeploy the container, reinstall the app: your history survives. No managed service anywhere.

06

A hub, not a dashboard

One page. Tasks, solver activity, live agent streams, approve/reject, manual add. Single file of vanilla JS, no build step. Open localhost:8787, bookmark it, close the terminal.

03 · how it compares

Two different trades. Both valid.

Motion-style tools are paying for themselves by running your scheduling in their cloud. That's a real service, and there's nothing wrong with paying for it. But it's worth being explicit about what you're trading for.

This
schedule-agent
  • $0/mo infra, ~$5/mo in API tokens
  • All data local, on your own machine
  • iCloud + Canvas + iMessage out of the box
  • Open source, MIT, audit-friendly
  • New integration = one file
  • You run your own Mac, Linux host, or container
The alternative
Motion, Reclaim, TimeHero
  • $19 – $34/month
  • Tasks and calendar copies live in the vendor's cloud
  • Opinionated integrations; no LMS support
  • Closed source
  • New integration happens on their roadmap
  • Zero hosting on your side
04 · install

Three ways in. Same app.

Pick based on how deep you want to go. The wizard is the same in all three — it writes a .env, creates your Anthropic agent, and drops you at the hub.

01

Terminal, one command fastest

Clone, make a venv, run the wizard in your browser. No packaging, no Gatekeeper warnings. This is how I run it. 

git clone https://github.com/YOUR-HANDLE/schedule-agent-public
cd schedule-agent-public
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python run.py
02

Docker headless

Self-contained image. Mount .env and state.db as volumes. Good for VPS or a home server. 

docker compose up -d --build

See docs/deployment.md for the systemd-on-Linux path too.

03

macOS app double-click

Packaged bundle. No Python, no Terminal. Unsigned for now — macOS will show a "cannot verify developer" warning on first launch. Right-click → Open to get past it. One click, forever. Code signing ($99/year to Apple) lands when the project earns it.

Download coming shortly. Build recipe lives at packaging/macos/ if you want to roll your own now.
